# Security Policy

## Supported Versions

Only the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately. Do not open a public issue.

To report a vulnerability:
- Submit a report via GitHub Private Security Advisories if enabled on this repository.
- Alternatively, email the repository owner.

You should receive a response within 48 hours. If the issue is confirmed, a patch will be developed and released. This is a personal project, so no bounties are currently offered.
